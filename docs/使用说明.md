# 使用说明

日常使用手册：从启动到各场景的具体操作。环境安装与配置项见 [配置说明](./配置说明.md) 和 README 快速开始。

## 启动与退出

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| **一键启动**（推荐） | 双击 `启动.bat` | 自动定位目录、装依赖、拉起桌面应用，加载完成后命令行窗口自动隐藏 |
| 命令行一键 | `python quick-start.py` | 同上；`--skip-install` 跳过安装，`--foreground` 保留控制台看日志 |
| 桌面模式 | `python start.py` | Electron 窗口 + 屏幕隐身 + 托盘 + 全局快捷键 |
| 浏览器模式 | `python start.py --mode network` | 局域网可访问（自动开启鉴权），手机扫码可用 |

- **窗口在哪**：桌面模式窗口无边框且**不在任务栏显示**，启动后直接在屏幕中央；也可在托盘（右下角小图标）左键单击，或按 `Ctrl+B` 显示/隐藏。
- **启动期隐身**：Windows 下主窗首帧先在屏幕外完成受保护的合成，约 80ms 后再移回屏幕中央，所以录屏/屏幕共享里不会出现启动瞬间的那一帧框。
- **退出**：窗口关闭按钮 = 真正退出（先优雅停止后端、刷盘复盘与 SQLite）；也可托盘右键 → 退出。
- **端口**：默认 18080，冲突时 `python start.py --port 9090`。

### 屏幕共享隐身

设置 → 工作模式里有「屏幕共享隐身」卡片，显示当前系统**实际**的隐身能力：

| 环境 | 表现 |
| --- | --- |
| Windows 10 2004+（build ≥ 19041） | 窗口从捕获画面中直接排除，真正的隐身 |
| Windows 更早版本 | 只能退化为黑块遮挡，反而可能引起注意，建议降低不透明度或改用提词模式 |
| macOS | 走 ScreenCaptureKit 排除路径，个别第三方录屏仍需实测 |

托盘菜单的「屏幕共享隐身」与设置页开关是同一份状态。**覆盖范围**：走系统窗口捕获 API 的会议/录屏软件（腾讯会议、钉钉、飞书、Zoom、OBS、Xbox Game Bar、系统截图等）；内核级监控客户端、硬件采集卡/HDMI、RDP 远程桌面、虚拟机宿主侧捕获、摄像头拍屏不在覆盖范围内。

## 实时辅助（面试主场景）

1. 启动应用后进入「实时辅助」面板。
2. 选择音频来源：**系统音频**（会议中对方声音，配置见 [音频配置](./音频配置.md)）或**麦克风**。
3. 点击开始，转写实时上屏；开启豆包流式 ASR 时边说边出实时预览（蓝色边框块）。
4. 识别到问句后自动触发多模型并行生成回答，流式输出到答案区。
5. 卡壳时：
   - 把问答框挂到旁边（悬浮窗，快捷键切换）；
   - 或截图审题（截屏区域可在设置里选半屏/全屏）。
6. 命中知识库笔记时，回答会引用本地资料，且输出上限自动放宽给出更完整答案。

常用全局快捷键（默认值，可在设置中改）：

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl+B` | 显示/隐藏主窗口 |
| 截图审题 | 截屏并自动作答 |
| 强制思考/非思考 | 提交截图时覆盖 think 开关 |
| 取消回答 | 中断正在生成的回答 |

## 知识库

1. 设置中开启知识库（`kb_enabled`），或直接在「知识库」面板上传文档。
2. 支持 `.md` / `.txt` / `.log` / `.docx` / `.pdf`；界面内可预览与阅读全文。
3. 检索会按触发模式自动参与：实时辅助 ASR 转写、手动文本检索、笔试模式。
4. 「最近命中」展示近期哪些转写触发了检索。

## 模拟面试

1. 新建会话：填公司 / 岗位 / 语言，可贴 JD 与简历快照（出题会结合，也可注入知识库上下文）。
2. 逐题作答：文字回答，或上传 WAV 语音（自动 ASR 转写后落库）。
3. 每题可生成**分维度点评**（含证据与改进建议）和**参考答案**（结合简历背景的示范回答）。
4. 会话完成后生成**整场报告**，可导出 Markdown 下载。
5. 支持从历史会话创建**练习会话**，针对弱项复练。

## 面试复盘

录制真实问答 → ASR 纠错 → 逐题分析 → 整场总结。复盘数据本地存储，不外传。

## 其他模块

- **能力分析**：知识点标签、历史问答、薄弱点趋势。
- **简历优化**：上传简历对照 JD 给出改写建议。
- **求职看板**：表格 / Kanban、状态标签、拖拽排序、Offer 对比。
- **设置中心**：模型管理、STT 引擎、主题、快捷键、截图区域等。
